## 🛠️ DEVELOPMENT GUIDELINES

### **Component Structure**
- Use React hooks for state management
- Prefer functional components
- Implement motion animations with Framer Motion
- Add `data-cursor` attributes for custom cursor labels
- Use Tailwind utility classes exclusively for styling

### **Adding New Content**
- Update config files in `src/config/` for data
- Create section components in `src/components/sections/`
- Use provided motion utilities from `src/lib/motion.ts`
- Maintain consistent typography and spacing
- Test responsiveness on all breakpoints

### **Animation Best Practices**
- Use `whileInView` for scroll-triggered animations
- Respect `prefers-reduced-motion` preference
- Keep animations under 800ms for snappy feel
- Use `staggerChildren` for list animations
- Add `viewport={{ once: false }}` to allow re-triggering

### **Performance Tips**
- Lazy load images with Next.js Image component
- Minimize re-renders with proper memoization
- Use CSS animations for performant effects
- Defer non-critical JavaScript
- Monitor Lighthouse scores
