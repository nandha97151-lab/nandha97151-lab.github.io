## 🌟 Key Features

- **11 Storytelling Chapters**: Sequential visual journey spanning identity, technical expertise, autonomous robotics, project showcases, certificate wall, and contact.
- **Cinematic Aesthetics**: High-contrast dark theme (`#000000`), crimson radial atmospheric glow (`#c9382b`), film grain noise overlay, and glassmorphism UI components.
- **Custom Interactive Mechanics**:
  - Custom lerping cursor with action state indicators.
  - Scroll-scrubbed typography reveal & letter dispersion logic.
  - Physical breaking clip-path puzzle section transition.
  - Interactive 3D CSS Robot Head following cursor coordinates.
  - PDF Resume download integration directly from navigation and contact links.
- **Zero-Dependency Architecture**: Built using pure HTML5, Vanilla CSS3, and ES6+ JavaScript for instant page loads and zero build step friction.

## 🚀 Local Development & Preview

To preview the portfolio locally, open `index.html` directly in any web browser, or launch a lightweight HTTP server:

```bash
# Python
python -m http.server 8000

# Node.js / npx
npx serve .
```

Then visit `http://localhost:8000`.

---

## 🌐 Deploying to GitHub Pages

1. Push all code to the `main` branch of `nandha97151-lab.github.io`.
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Set branch to `main` and folder to `/ (root)`.
5. Save changes. Your site will automatically publish at `https://nandha97151-lab.github.io`.
