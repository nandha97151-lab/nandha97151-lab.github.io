# PORTFILO-2.O

Premium, cinematic, scroll-driven personal portfolio website for **Nandhakumar N**, a B.Tech Artificial Intelligence & Data Science student at KPR Institute of Engineering and Technology.

## 🌟 Features
- **Storytelling Chapters**: 11 sequential visual chapters from Darkness to Identity, Intelligence, Projects, 3D Robotics, and Contact.
- **Cinematic Aesthetics**: High-contrast dark theme, crimson radial glow, SVG film grain noise overlay, and glassmorphism UI components.
- **Custom Mechanics**:
  - Custom cursor with dynamic lerping ring & action labels.
  - Scroll-scrubbed typography revealing & letter dispersion.
  - Physical breaking Puzzle Transition using CSS polygon clip-paths.
  - Interactive 3D CSS Robot Head following mouse coordinates.
  - Camera shutter flash transition before revealing selected works.
  - Full project detail overlay modals with performance metrics.
- **Vanilla Tech Stack**: Built purely using HTML5, CSS3, and JavaScript with zero external frameworks or build steps.
- **Decoupled Data**: Configured via `content.js` for easy data edits.

## 🚀 Quick Start
Simply open `index.html` in any modern web browser, or serve locally:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.
